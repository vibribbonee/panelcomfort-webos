SCHEDULE

Brightness & fade

When custom Movie Mode brightness is off, Movie Mode uses each output's day maximum. When enabled, this sets the TV target and maps the same position between the TV's night/day limits onto HyperHDR's own night/day limits.

Durations use hours:minutes. For example, 1:05 means 1 hour and 5 minutes. Coordinates are used for sunset/sunrise triggers and solar-elevation mode. The schedule does not restart its fade if the TV wakes partway through.

EYE COMFORT

Separate evening setting

Dynamic follows fresh lux, then falls back to this schedule when readings are stale. Time follows this schedule only and ignores lux. Movie Mode pauses both; On and Off are explicit overrides.

Changes stay on the TV and apply after any current update finishes.

EXTERNAL SENSOR

Send a lux reading

For a smart light sensor that can reach the TV, no Home Assistant integration needed.

Alternatively, enable Webhooks in the TV app and use its secret URL ending in ?ambient_lux=0, replacing 0 with the measured value.

Sensor state is model- and integration-dependent.

AMBIENT RESPONSE

Lux mapping

Map room illuminance to the same TV and HyperHDR brightness range. A Home Assistant lux sensor is optional.

At or below the minimum lux, night targets apply; at or above the maximum, daytime targets apply. While fresh lux data is available, evening and morning triggers are ignored. Those triggers are fallback only when sensor data is missing or stale.

AMBIENT LEDS

Hyperion / HyperHDR brightness

Lux modes only. The LEDs drop faster than the screen as the room gets darker and still reach the day maximum in full light.

Movie Mode uses the shared Movie Mode brightness when enabled; otherwise it uses this daytime maximum. Connection and instance selection stay in the TV app.

EXTRASSolar locationLatitude & longitude · optional unless solar mode is selected

Coordinates are used for sunrise/sunset triggers and solar-elevation mode. Internet geolocation is approximate; you can enter coordinates from a trusted map manually.

The browser dashboard does not perform IP geolocation. Use the TV app's Extras tab if you want it to try an approximate lookup.
