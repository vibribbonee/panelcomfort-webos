AMBIENT LIGHTS

Hyperion / HyperHDR brightness

Fade HyperHDR output with the TV schedule. Uses HyperHDR v22 output scaling and can target all running instances or selected instance IDs. Each instance is selected before its brightness is changed, so separate side-light instances can follow the schedule too. If HyperHDR or a light is unavailable, TV dimming keeps running.

Save & apply, then test the connection.
